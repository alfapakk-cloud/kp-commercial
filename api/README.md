# kp-commercial-api

Здесь хранится привязка Cloudflare D1, необходимая Worker `kp-commercial-api`.

## D1 binding

Файл `wrangler-bindings.jsonc` фиксирует `DB` → база `kp-commercial`. При подготовке полного Wrangler-конфига этот блок `d1_databases` нужно сохранить без изменений.

## Секрет

`ADMIN_API_SECRET` остаётся секретом в Cloudflare. Не добавляйте его значение в Git или Wrangler-конфигурацию.

## Важно перед публикацией

В репозитории сейчас нет исходника Worker, поэтому эта папка пока содержит только ресурсную привязку и не является самостоятельной точкой деплоя. Перед переходом на деплой через Wrangler нужно добавить сюда полный актуальный исходник Worker и собрать полный `wrangler.jsonc`. До этого публикуйте API тем способом, который сохраняет обе привязки — `DB` и `ADMIN_API_SECRET`.
